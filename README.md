# Data Projects Portfolio

One-page portfolio for Susannah Bear's data analytics and data science projects.

Plain HTML, CSS and JavaScript, with no build step. Open `index.html` or serve the folder with any static host (for example GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/`).

- Swap the background photo: change `--bg-image` at the top of `styles.css`.
- Project cards, About timeline and contact details live in `index.html`.
